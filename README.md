# Booking Management System

The **Booking Management System** is a web-based system designed to manage bookings for beauty service resources.

The system allows administrators and staff to manage resources, availability, bookings, clients, staff records, payments, and booking reports in one centralized system.

## Users

### Admin

* Manage resources
* Manage bookings
* Search booking details
* Manage client and staff records
* View booking history
* View reports

### Staff

* Create booking details
* Update booking status
* View booking status
* Reschedule bookings
* Cancel bookings
* Search booking details
* View booking history

## Resources

* Makeup Artist
* Hair Stylist

## Core Features

* Resource Management
* Availability Management
* Booking Management
* Payment Management
* Client and Staff Management
* Booking History
* Reports

## Booking Rules

* A resource must be available before it can be booked.
* A resource cannot have overlapping bookings.
* Booking date and time must be valid.
* Staff can change or cancel bookings.
* Completed and cancelled bookings are included in reports.
